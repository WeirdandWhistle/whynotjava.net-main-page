List of Little fixes that I never remeber

Run TLOU 2 through proton:

PROTON_DISABLE_NVAPI=1 PROTON_HIDE_NVIDIA_GPU=1 WINE_USE_KWIN_HACKS=1 PROTON_ENABLE_WAYLAND=1 %command%
note:remove WINE_USE_KWIN_HACKS if not on KDE

Disable firefox's terrible UI update:

in about:config set browser.nova.enabled to false

Enbaled/disable updating a package in pacman:

in /etc/pacman.conf under [options] put the package name in IgnorePkg
note: packages are seperated by commas.
The entire file can be reset by replacing it with
/etc/pacman.conf.pacnew on CachyOS

Make file wildcards:

I quote The $< is the input" of the rule, $@ is the "output" meaning...
use them in such a way:

.c :
	$(CC) $(CFLAGS) -c -o $@ $<
